Leafdraw

Procedural leaves built from botanical terms. Every outline, tooth and vein follows a numeric definition from the glossary of leaf morphology and the Manual of Leaf Architecture.

Tier A species are fitted from measured herbarium specimens, tier B from curated literature values checked against Wikipedia and POWO, and tier C (any species) from that species' published leaf description plus family templates. Same species and seed always draw the same leaf. The command line tool writes the same drawings to files: leafdraw -s "Quercus alba" --seed 7 --style botanical -o oak.svg
